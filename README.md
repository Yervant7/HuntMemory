# New release. HuntMemory now doesn't necessarily require a kernel patch to work. You can use it without a patch, but it will likely be detected by detection tools. Of course, this doesn't mean there's no way to hide it. I created a patch for Android ARM64 kernels that completely hides it. To get more information about the patch, visit https://t.me/huntMemory7.
